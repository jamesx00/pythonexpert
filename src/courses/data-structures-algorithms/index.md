## Course Summary &#x1F4D7;

This course walks through the core patterns behind most coding-interview questions: arrays and hashing, two pointers, sliding window, stacks, binary search, linked lists, trees, tries, heaps, backtracking, graphs, dynamic programming, greedy algorithms, intervals, math, and bit manipulation. Instead of memorizing individual problems, you'll learn to recognize the *pattern* behind a problem and reuse it.

The problem set and ordering are inspired by the well-known "150" style interview roadmaps that group problems by pattern rather than difficulty, moving from foundational techniques to more advanced graph and dynamic-programming problems.

## What Will You Learn? &#x1F9D0;‍🎓

- **Pattern recognition:** Learn to spot which technique (two pointers, sliding window, backtracking, etc.) applies to a new problem.
- **Core data structures:** Get hands-on practice with arrays, hash maps, stacks, linked lists, trees, tries, and heaps in Python.
- **Algorithmic techniques:** Binary search, BFS/DFS, backtracking, greedy strategies, and dynamic programming (both 1-D and 2-D).
- **Problem-solving speed:** Each lesson is a self-contained coding exercise with instant test feedback, so you can practice at your own pace.

## Who Is This Course For? &#x1F468;‍&#x1F393;

- **Interview candidates** preparing for technical coding interviews at software companies.
- **Python programmers** who already know the language basics (see our [Learn to program with Python](/courses/basic-python/) course) and want to build algorithmic problem-solving skills.
- **CS students** who want structured, pattern-based practice to complement their coursework.

**Note:** This course assumes you're comfortable with basic Python syntax, functions, and data structures. If you're new to Python, start with our beginner course first.
